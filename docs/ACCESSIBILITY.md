# Accessibility Statement

For Your Service is committed to ensuring digital accessibility for veterans of all abilities.

## Standards

We conform to WCAG 2.1 Level AA standards.

## Features

### Screen Reader Support
- Semantic HTML
- ARIA labels
- Alt text for images

### Keyboard Navigation
- Tab navigation supported
- Keyboard shortcuts available
- Focus indicators visible

### Visual
- High contrast mode
- Resizable text
- Color-blind friendly
