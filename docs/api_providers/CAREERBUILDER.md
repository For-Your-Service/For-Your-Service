# CareerBuilder API Integration

## Overview
Major job board with 24+ million registered users.

## API Access
* **Endpoint:** `https://api.careerbuilder.com/v2/`
* **Authentication:** API Key (Developer Key)
* **Rate Limit:** 100 requests/minute

## Job Search
`GET /jobsearch`

### Parameters
* `DeveloperKey` - Your API key
* `Keywords` - Job search keywords
* `Location` - City, state, or zip code
* `Radius` - Search radius (miles)
