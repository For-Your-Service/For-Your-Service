# 🔄 Git Commit Workflow Guide

## Quick Reference

### Throughout the Day - Just Say:

- **"commit"** → Auto-commit with timestamp
- **"commit: [message]"** → Custom commit message
- **"git status"** → See what changed
- **"push"** → Push to GitHub

---

| Time | Trigger | Example Message |

## Commit Types

### 🔹 Micro-commits (Every 30-60 min)
```
commit: WIP - working on scraper
commit: Progress checkpoint - 2PM
commit: Testing API connections
```

### 🔹 Feature commits (When something works)
```
commit: Add Adzuna API scraper
commit: Complete Bronze layer schema
commit: Build data normalization pipeline
```

### 🔹 Documentation commits
```
commit: Update README with API setup instructions
commit: Add data flow architecture diagram
commit: Document scraper configuration
```

## Why Commit Often?

✅ Shows continuous work throughout the day
✅ Makes it easy to roll back if needed
✅ Creates detailed project history
✅ Demonstrates progress to stakeholders (7 Eagle Group)
✅ Protects your work (cloud backup)
